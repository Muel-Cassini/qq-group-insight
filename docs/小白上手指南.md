# 零基础上手指南：从 QQ 群聊记录到一份完整汇总

> 这份文档假设你**完全没接触过命令行**。所有需要你做的事，都写成了可以直接复制粘贴的命令。
> 全程只做三件事：**导出数据 → 让脚本处理 → 让 AI 写总结**。

---

## 项目位置（先确认这一件事）

本项目已经归档到这里：

```
D:\summary-workspace\
```

下文出现的 `<项目根>` 都指这个目录。**如果以后你又移动了这个文件夹**，把下面所有命令里的路径换成新位置即可。
（本文档里的命令都按"项目根"的相对路径书写，只要先 `cd` 进项目根，命令本身不用改。）

---

## 第 0 步：先搞懂这份汇总长什么样（1 分钟）

最终你会得到四个文件（都在 `artifacts\qq\<群名>-<日期区间>\` 里）：

| 文件 | 里面是什么 | 你怎么用 |
|---|---|---|
| `digest\2026-09-09.md` 等 | 每天的汇总：谁在几点说了什么，按"公告通知/提问求助/资源分享/技术讨论/闲聊/广告"分类，每条都标了重要度 P0~P3 | 想按天看，打开这些 |
| `p1-todo.md` | 四天里所有"需要你关注"的消息（P0 必须知道、P1 待办） | 只想看重点，打开这个 |
| `media-index.md` | 群里发过的图片/文件清单，含磁盘路径、发送人、时间 | 想找某张图 |
| `normalized.jsonl` | 机器可读的完整数据 | 给 AI 做交叉比对用，你不用直接看 |

重要度含义：**P0**=决策/截止/紧急通知（必须知道）｜**P1**=@我、待办、求助、真问题（要行动）｜**P2**=有信息的资源与技术讨论｜**P3**=闲聊。

## 第 1 步：认识四个名词（2 分钟）

1. **PowerShell**：Windows 自带的"命令窗口"。按 `Win` 键，输入 `powershell`，回车就打开了。
2. **命令**：一行文字，粘贴进 PowerShell 按回车，电脑就会照做。本文所有命令都是这种。
3. **项目根**：就是 `D:\summary-workspace` 这个文件夹——所有工具、数据、结果都住在里面。
4. **技能（skill）**：三个自动化的"办事流程"，已经装好放在 `.agents\skills\` 里：解析群聊、采集社媒、做交叉比对。

⚠️ 只有一条铁律：**复制命令时不要漏掉开头的 `python`，也不要把命令里的引号改成中文引号**。

```powershell
cd "D:\summary-workspace"
```

之后**所有命令都在这个目录下执行**。如果你中途关了窗口，重新打开后要再执行一次这一行。

## 第 3 步：准备数据（两条路，任选）

### 路线 A：用群里已有的导出（你目前就是这条）

群里已经有导出好的记录，放在：

```
D:\summary-workspace\data\qq-chat-exporter\exports\
```

先确认文件名（把下面命令粘进去，它会列出来）：

```powershell
Get-ChildItem "data\qq-chat-exporter\exports" -File | Select-Object Name, @{n="大小MB";e={[math]::Round($_.Length/1MB,2)}}
```

你会看到类似 `group_示例群A_1011090214_20260912_214920323.json` 的文件。**记住这个文件名**，下一步要用。

### 路线 B：自己重新导出一份（想加新群或更新记录时）

1. 双击运行 QCE（QQ Chat Exporter）：`%LOCALAPPDATA%\QQChatExporter\QQ Chat Exporter.exe`；
2. 浏览器会自动打开界面 <http://localhost:40653/qce>；如果提示要令牌（token），看那个黑色控制台窗口里打印的字符；
3. 左边选你要汇总的**群**；
4. 点导出，格式选 **JSON**；
5. **一定要勾选"下载图片/文件/表情"**（不勾的话，汇总里只有图片文件名，看不到图片内容）；
6. 输出目录填：`D:\summary-workspace\data\qq-chat-exporter\exports`；
7. 等它跑完（群里图片多的话要几分钟），回到 PowerShell 执行第 3 步路线 A 的那条命令确认文件已生成。

## 第 4 步：生成群聊汇总（1 分钟）

把**第 3 步看到的文件名**替换到下面命令里（注意保留引号），粘贴回车：

```powershell
python .agents/skills/qq-group-summary/scripts/qq_group_digest.py `
  --src "data/qq-chat-exporter/exports/group_示例群A_1011090214_20260912_214920323.json" `
  --out "artifacts/qq/示例群A-20260909-20260912" `
  --media-root "data/qq-chat-exporter/exports" `
  --media-check
```

不想逐个填文件名？也可以直接把**整个目录**丢给它，它会自动处理里面所有导出文件：

```powershell
python .agents/skills/qq-group-summary/scripts/qq_group_digest.py `
  --src "data/qq-chat-exporter/exports" `
  --out "artifacts/qq/全部群-$(Get-Date -Format yyyyMMdd)" `
  --media-root "data/qq-chat-exporter/exports" --media-check
```

**怎么判断成功**：最后一行会输出类似

```
{"files": 1, "messages": 1778, "days": [...], "out": "...", "skipped": 0, "no_time": 0}
```

`skipped: 0` 表示没有解析失败的消息。然后打开结果文件夹看看：

```powershell
explorer "artifacts\qq\示例群A-20260909-20260912"
```

`digest` 文件夹里是按天分的汇总，先打开 `p1-todo.md`——这就是"要我关注的事"清单。

> 想先拿假数据练手不怕搞坏东西？执行下面这条，它用内置的小样例（9 条消息）跑一遍：
> ```powershell
> python .agents/skills/qq-group-summary/scripts/qq_group_digest.py --src "artifacts/_samples/qq" --out "artifacts/qq/_练习"
> ```

## 第 5 步：准备社媒采集（第一次要花 5 分钟）

跳过这一步就只能做"群聊内部汇总"，不能和社媒对照。要做对照就按下面来。

### 5.1 启动一个"可被程序控制"的 Edge

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "tools\launch-edge-cdp.ps1"
```

看到 `CDP 就绪：Edg/153.x` 就是成功了，同时会弹出一个新的 Edge 窗口。
（这个窗口用独立配置，和你日常 Edge 互不影响。关掉它用：`... -File "tools\launch-edge-cdp.ps1" -Kill`）

### 5.2 在这个 Edge 窗口里登录三个平台

在**刚弹出的那个** Edge 窗口里，分别打开并登录（扫码即可）：

- 小红书：<https://www.xiaohongshu.com>
- 知乎：<https://www.zhihu.com>
- B站：<https://www.bilibili.com>

登录状态会保存在那个调试配置里，一般不用重复登录，但**会过期**。

> **怎么知道自己是不是掉登录了？** 不用猜：采集与关键词验证在开跑前都会自动做一次真实登录判定，
> 未登录 / 已过期会立刻报错并点名是哪个平台，不会再让你干等 8 分钟。
> 特别注意：**cookie 还在 ≠ 登录有效**——实测小红书会保留 `web_session`，但打开个人页仍会被重定向到登录页。

### 5.3 验证一下采集链路（可选但推荐）

```powershell
python .agents/skills/social-crawl/scripts/crawl.py --platform xhs --keywords "Docker 容器" `
  --limit 3 --no-comments --out "artifacts/social/_练习"
```

跑完会打印 `{"exit_code": 0, "files": N, ...}`。`exit_code: 0` 且 `files` 大于 0 就算通了。

## 第 6 步：采集社媒内容（3 分钟）

关键词就是你想在社媒上找的东西，建议**从第 4 步的汇总里挑话题**（比如群里在聊"华为宣讲""保研分流""agent 面试"）。

```powershell
# 小红书
python .agents/skills/social-crawl/scripts/crawl.py --platform xhs `
  --keywords "华为 校招 宣讲" --limit 20 --comments-per-item 20 `
  --out "artifacts/social/$(Get-Date -Format yyyyMMdd)-xhs-示例关键词"

# 知乎
python .agents/skills/social-crawl/scripts/crawl.py --platform zhihu `
  --keywords "华为 校招" --limit 15 --out "artifacts/social/$(Get-Date -Format yyyyMMdd)-zhihu-示例关键词"

# B站
python .agents/skills/social-crawl/scripts/crawl.py --platform bili `
  --keywords "华为 校招 面经" --limit 10 --no-comments `
  --out "artifacts/social/$(Get-Date -Format yyyyMMdd)-bili-示例关键词"
```

小提示：

- `--keywords` 里多个词用空格隔开即可（如 `"agent 面试 runtime"`）；
- 想先看它会执行什么而不真的抓取，加 `--print-cmd`；
- 每个 `--out` 目录名记下来，第 7 步要用。

## 第 7 步：交叉比对（1 分钟）

把两侧目录填进去（`--social` 可以只填一个平台的目录，也可以分别跑多次）：

```powershell
python .agents/skills/cross-compare/scripts/compare.py `
  --qq "artifacts/qq/示例群A-20260909-20260912" `
  --social "artifacts/social/20260913-xhs-示例关键词" `
  --out "artifacts/compare/20260913"
```

结果里有两份东西：

- `compare.md`：人可读的比对报告（共同主题 / 高相关配对 / 单边主题 / 时效性）；
- `compare.json`：给 AI 用的结构化数据。

`pairs: 0`（没有配对）说明两边话题差太远或阈值偏高，属于正常情况，可以换个关键词再采一遍。

## 第 8 步：让 AI 写出最终汇总（关键一步）

在 DSH 里对我说这句话就够了（把路径换成你自己的）：

> 读 `artifacts\compare\20260913\compare.md` 和 `artifacts\qq\示例群A-20260909-20260912` 里的 digest，帮我写一份完整汇总。

我会按 `cross-compare` 技能里定好的要求来写，输出结构是：

1. 一句话结论；
2. 交叉印证的关键结论（每条都带来源：群聊写"群名 时间 发送人"，社媒写"标题 + 链接 + 作者/互动量"）；
3. 群聊盲区（社媒有、群里没提到的）；
4. 群聊私有价值（群里独有、社媒没有的经验）；
5. 冲突与待核实清单（两边说法矛盾或可能过时的）；
6. 建议的下一步动作。

⚠️ **一个已知限制**：图片内容需要"能看图的模型"。如果当前模型不支持图片输入，我会明确告诉你"图片未读取"，而不是瞎猜图片里是什么。想让我连图片一起读，先在 Web 界面右上角把模型切换成支持视觉的模型，再让我重跑第 4 步到第 8 步。

## 第 9 步：日常怎么重复使用

- **有新聊天记录** → 重新导出（第 3 步路线 B）→ 重跑第 4 步；
- **想加新话题** → 直接跑第 6 步，换个关键词即可；
- **想自动每天导出** → 在 QCE 界面里建"定时导出"任务，输出目录填 `D:\summary-workspace\data\qq-chat-exporter\scheduled-exports`，之后定期重跑第 4 步（`--src` 指向那个目录）；
- **产物越积越多** → `artifacts\` 里的东西随时可以删，需要时用 `data\` 里的原始数据重新跑出来。

## 常见问题（照着查）

| 你看到的 | 意思是 | 怎么办 |
|---|---|---|
| `python : 无法将"python"项识别为...` | Python 没装好或没进 PATH | 本工作区已装：用完整路径 `.venv\Scripts\python.exe` 代替 `python` |
| `无法加载文件 ... 因为在此系统上禁止运行脚本` | 执行策略限制（`.ps1` 脚本） | 用文档里给的完整写法 `powershell -NoProfile -ExecutionPolicy Bypass -File "..."` |
| `未找到 .../tools/MediaCrawler/main.py` | 你把 `tools` 目录挪走了 | 把它移回工作区根目录（目录结构见 `README.md`） |
| 命令粘进去报一堆红字但末尾有 `{"files":...}` | 只是控制台把日志当错误显示 | 看最后那行 JSON 判断是否成功 |
| 中文显示成乱码（仅控制台） | PowerShell 控制台编码问题 | 文件本身是好的，用记事本/VSCode 打开正常；要控制台也正常就先执行 `$env:PYTHONIOENCODING="utf-8"` |
| 汇总里钟点和 QCE 界面差 8 小时 | QCE 导出的 `time` 字符串本身有 8 小时偏差，脚本以时间戳为准 | 属预期行为，日期分组不受影响（详见 `GUIDE.md` 第 6 节） |
| 媒体清单全是"未校验" | 没加 `--media-check` | 命令里补上 `--media-check` 与 `--media-root` |
| 采集 `CDP port 9222 is not accessible` | Edge 调试实例没启动 | 重跑第 5.1 步；或在采集命令末尾加 `--launch-edge` |
| 采集取不到数据 | 调试用的 Edge 里没登录该平台 | 在那个窗口登录后重试；程序现在会在采集前自动判定登录并直接报错 |
| 提示「xhs 未登录或登录已过期」 | 登录态服务端已失效（cookie 还在也没用） | 到调试 Edge 窗口重新扫码登录后重试 |
| 配对 0 组 | 两边话题不重叠或阈值偏高 | 换更具体的关键词重采，或让我把 `config.json` 里的 `min_score` 调低 |

## 想调规则（进阶，可选）

三个技能各有一个 `config.json`，**改完立刻生效，不用改代码**：

- `.agents\skills\qq-group-summary\config.json`：主题分类关键词、P0/P1 判定规则、预览长度；
- `.agents\skills\social-crawl\config.json`：默认平台/浏览器、限流护栏（超限会提示风控风险）；
- `.agents\skills\cross-compare\config.json`：比对主题词表、相似度权重与阈值。

具体每一项的含义与调参经验，见各自目录下的 `GUIDE.md`。拿不准就直接告诉我要调什么（比如"广告太多，把广告规则收紧点"），我来改。
