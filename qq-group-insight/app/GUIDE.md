# 本地控制台使用说明（零基础可照做）

> 目标：不用敲命令，点按钮完成「群聊汇总 → 社媒采集 → 关键词验证 → 交叉比对 → 文件汇总 → 生成总结」。
> 如果你更习惯命令行，三个技能的 `GUIDE.md` 里有等价命令。

---

## 一、启动与关闭

**启动**：双击 `app\启动.cmd`（或在 `app` 目录执行 `node server/main.mjs`）。

启动流程（那个黑色窗口会逐行打印）：

1. 挑一个空闲端口起本地服务（默认从 7801 往后找）；
2. 等端口真正可连接后才继续（避免「网页打不开」的竞态）；
3. 确保 **Edge 调试实例**在跑（端口 9222，独立配置 `%LOCALAPPDATA%\dsh-edge-cdp`）；
4. 确保 **DSH** 在跑（端口 3080）；
5. **把界面开在受控的 Edge 实例里**——也就是自动弹出的那个 Edge 窗口中会多出一个标签页
   「群聊汇总 × 社媒交叉比对 · 本地控制台」。

> ⚠️ 界面开在**这个调试 Edge 窗口**里，不是你自己日常打开的浏览器窗口。
> 第一次用时若只看到黑窗口、没看到界面，请到那个 Edge 窗口的标签栏找一下；
> 找不到就手动访问窗口里打印的地址（形如 `http://127.0.0.1:7801/`）。
> 调试实例起不来时，程序会自动退回用系统默认浏览器打开。

**关闭**：关掉那个黑色命令行窗口即停止控制台（Edge 与 DSH 会继续运行，下次启动直接复用）。

**只想重开界面**：Edge 窗口关掉了也没关系，直接访问 `http://127.0.0.1:7801/`；或重新双击 `启动.cmd`（服务在跑时会直接复用）。

## 二、第一次使用前的准备（只需一次）

1. **在 Edge 调试窗口里登录**：启动后会自动弹出一个 Edge 窗口，在里面分别打开并登录
   小红书（xiaohongshu.com）、知乎（zhihu.com）、B站（bilibili.com）。登录态会长期保存在那个独立配置里。
   > 登录会**过期**。采集和关键词验证在开跑前都会自动做一次真实登录判定（见 ②③ 两节），
   > 判定不通过会**直接报错并告诉你哪个平台需要重新登录**，不会再让你干等 8 分钟。
2. **确认导出数据存在**：QQ 群聊导出（QCE）应输出到
   `data\qq-chat-exporter\exports\`（手动导出）或 `data\qq-chat-exporter\scheduled-exports\`（定时导出）。
   导出时**务必勾选下载图片/文件/表情**，否则汇总里看不到图片内容。
3. （可选）**配置 AI**：要用"自有 API"这条路，去「设置 → AI 服务 → 新增服务」填 Base URL、模型名、API Key。
   只用"本地 DSH"这条路则不需要配置。

## 三、六个页面怎么用

### 界面布局可以自己调（拖动调整大小）

- **左右拖动**侧边栏右侧那条竖线 → 调整侧边栏宽度（150–520px）；
- **上下拖动**日志区上方那条横线 → 调整底部「当前进程 + 运行日志」的高度（120–900px）；
- **双击**任一分隔条 → 恢复默认尺寸（侧边栏 220 / 底部 340）；
- 尺寸存在浏览器本地（`localStorage`），下次打开沿用。

### ① 导出与汇总

- 点「扫描」列出所有导出：群名/群号、时间范围、消息数、大小、是否已汇总。
- 勾选一个或多个导出 → 「汇总选中项」；表单里每个文件也可以单独点「汇总」。
- **每次汇总会产生两类报告**：
  - `overall.md` —— **整体汇总**（覆盖全部聊天记录的总览：重要度分布、主题分布、按天分布、全部 P0/P1、发言排行、各主题要点、链接与媒体统计）；
  - `digest/<日期>.md` —— 每日汇总（按天切分）。
- 汇总产物出现在下面「汇总产物」表里，产物列会标出「整体汇总 · p1待办 · 媒体清单 · 原文」，可「打开」目录、「预览」内容、或点「AI 复判」。
- 点「预览」时下拉默认就是 `overall.md`，也可以切到某一天的 digest、`p1-todo.md`、`media-index.md`、`_report.md`。
- 「归档选中项」把导出移到 `data/qq-chat-exporter/archive/`；「删除选中项」移到**回收站**（可恢复）。
- 「内容预览」下拉可以看 `p1-todo.md`、每日 digest、`_report.md` 等产物全文。

#### ①-2 单条聊天记录汇总（单独挑一条来汇总）

「导出记录」下面是**单条聊天记录汇总**区域：不想用表格勾选时，直接在下拉里挑一条即可。

1. **选聊天记录**：下拉列出**扫描到的全部记录**（手动导出 + 定时导出），每条显示 `[手动/定时] 群名 · 时间范围 · 消息数`，
   并且**包含已经汇总过的**（不勾「隐藏已汇总」也能在这里选到），已汇总的会带「已汇总」标记。
   选好后下面一行会显示这条记录的详情（群号 / 消息数 / 大小 / 记录内时间范围 / 导出时间 / 是否已汇总）。
2. **参数（都可以留空）**：

   | 参数 | 说明 |
   |---|---|
   | 起始 / 结束日期 | 留空 = 汇总这条记录的**全部**消息；填了只汇总区间内的消息。点「用该记录的时间范围填充」可一键填入它自带的范围 |
   | 只汇总会话名包含 | 留空 = 全部。按**子串**匹配、不区分大小写（多会话导出时用它筛） |
   | 输出目录 | 留空 = 自动命名到 `artifacts/qq/<群名>-<起止>/`。可填项目内相对路径，也可填**绝对路径**（例如 `D:\汇总\xxx`）。相对路径用 `../` 跑到项目外会被拒绝 |
   | 校验媒体文件 | 默认勾选；关掉则只统计不校验图片/文件是否缺失 |

3. 点「**汇总这一条**」开始；产物与「汇总选中项」完全一致（`overall.md`、`digest/<日期>.md`、`p1-todo.md`、`media-index.md`、`normalized.jsonl`），
   并出现在下面「汇总产物」表里。
4. 「打开已有产物」在这条记录已汇总时可用，直接打开它的汇总目录；「刷新列表」重新扫描导出目录。

### ② 采集与关键词

- 选平台（小红书/知乎/B站等）与模式：
  - **关键词搜索**：填关键词，多个用空格分隔；
  - **指定笔记/帖子链接**：填笔记 ID 或完整 URL（Detail 模式）；
  - **指定创作者主页**：填创作者 ID 或主页 URL（Creator 模式）。
- 「只看命令」会弹出实际会执行的命令，便于确认再跑。
- **AI 关键词推荐**：选一份群聊汇总 → 点「推荐关键词」→ 出来的关键词点一下即填入采集框。
- 下面是「采集批次」列表，可打开结果目录。

> **采集前会自动检查登录**：点「开始采集」后先跑一次登录判定（约 10–30 秒），
>   已登录的平台继续，未登录的平台会**跳过并在日志里说明原因**；若全部平台都未登录，任务直接失败并提示你去 Edge 调试窗口重新登录。
>   注意：cookie 还在不等于登录有效——实测小红书会保留 `web_session`，但个人页仍会被重定向到登录页。

### ②-3 关键词验证（把关键词拿到社媒上做跨平台互比）

在「采集与关键词」页的下半部分，流程是**本地提取或手打关键词 → 逐平台检索 → 跨平台互比 → 汇总**。
关键词不一定要来自群聊：输入框里可以直接手打任意词（逗号/换行分隔）。

1. **挑群聊汇总** → 点「提取候选关键词」：用本地 jieba + TF-IDF 从汇总的 `normalized.jsonl` 里提词，
   自动过滤群昵称里的高频碎片，并对领域词（就业/考试/校园等）加权。**这一步不联网、不调用 AI、不花钱**。
   （只想手打关键词的话，这一步可以跳过。）
2. 候选词以卡片形式列出（带词频与分值），**点一下加入 / 再点取消**；也可以用输入框手动补词或改词。
3. 选平台 → 选**比对方式**与**汇总引擎** → 填条数与评论数 → 点「开始验证」。

**比对方式**：

| 选项 | 说明 |
|---|---|
| 纯社媒跨平台互比（默认） | 只把同一个关键词在各平台采到的内容**互相比对**，不需要群聊 |
| 跨平台互比 + 群聊对照 | 在上面基础上，额外用「含该关键词的群聊消息」当左侧再比一次，并做 AI 判定（需要选一份群聊汇总） |

**汇总引擎**（页面下方会显示当前实际会用哪条）：

| 选项 | 说明 |
|---|---|
| 自动（默认） | 配了可用的 AI 服务就用大模型；没配（或调用失败）就自动用本地规则 |
| 只用本地规则 | 强制本地规则汇总，**不联网、不花钱** |
| 只用 AI | 强制大模型（没配会失败） |

跨平台互比会算出四类东西：**共识主题**（≥2 个平台都在讨论）、**平台独有视角**（信息差线索）、
**跨平台高相关配对**（不同平台在讲同一件事，可作交叉印证）、**疑似同源/搬运**（不能当两个独立信源）。

产物在 `artifacts\keywords\verify-<时间戳>\`：

| 文件 | 内容 |
|---|---|
| `verify-report.md` | **材料索引**：逐词的采集目录、跨平台互比材料、群聊对照、AI 判定结果 |
| `verify-summary.md` | **面向人的汇总**：本地规则版或 AI 版，文件头会标注「生成方式」 |
| `<关键词>\_platform\platform-compare.md` | 该词的跨平台互比材料（平台画像、主题×平台矩阵、配对、同源） |
| `<关键词>\_platform\keyword-summary.md` | 该词单独的一份本地汇总 |
| `<关键词>\<平台>\` | 该词的原始采集结果（JSONL 与清单） |
| `<关键词>\_qq\`、`_compare\` | 仅「跨平台互比 + 群聊对照」时产出 |

**跟 AI 的关系**：没配 AI 时照样能跑完整条链路并出汇总（本地规则版，只做归并/摘录/计数）；
到「⑥ 设置」配好服务后重新跑一次，同名汇总文件会自动变成大模型版（结论更深），不用改任何参数。

**耗时提示**：成本 ≈ 关键词数 × 平台数 次采集，每个平台单次最长等 8 分钟；建议先只选 1–2 个词 + 1–2 个平台试跑。

### ③ 交叉比对

- 选「群聊汇总」+「采集批次」→「开始比对」，几秒到几十秒出结果。
- 结果在「比对结果」表里，点「查看比对材料」看 `compare.md` 全文。
- **AI 判定**：选比对结果目录 → 「开始 AI 判定」，会给每组配对标出 **印证 / 补充 / 冲突**，
  结果写入该目录下的 `compare-ai.md` 并在预览区显示。

### ④ 总结

三条路，任选（设置页可以设默认）：

| 方式 | 说明 | 需要什么 |
|---|---|---|
| 用本地 DSH | 走 `dsh --profile headless`，能读技能材料、也能看图片；**跑完会自动删掉 DSH 里这次产生的会话** | 什么都不用配；消耗 DSH 的模型额度 |
| 用我的 API | 由本应用直接调你填的 AI | 需在设置页配置服务与 Key |
| 只生成提示词 | 把材料拼成一份提示词文件，自己复制到任意 AI | 无 |

- 可选「**原文深度模式**」：按天把所有原始消息分块送给 AI，逐日总结再合并（更准、更贵）。
- 「**指定关键词**」：填了就只围绕这些词组织总结（与关键词验证用的是同一批词）。
- 「**附加上传文件**」：多选 ⑤ 文件汇总页里上传/解析过的批次，把**群聊 + 文档**一起总结；解析好的 `all-in-one.md` 会作为附加材料送进去。
- 「风格要求」「重点关注」是自由填写项，例如 `重点关注内推与截止时间，忽略闲聊`。
- 走 API 时，点「用我的 API 生成」会先弹出确认框，显示**预估 token 与预估费用**，确认后才发送。
- 生成结果默认写入 `artifacts\summary\`，可在页面下方「历史总结」里查看全文。

**关于 DSH 会话清理**（本地 DSH 方式）：

- 每次点「用本地 DSH 生成」，DSH 会新建一个会话；任务结束后应用会**自动删除这一个会话**，
  并在日志区打印 `[DSH] 已清理 1 个本次任务产生的会话：session-xxxx`。
- 判定依据是「运行前后的会话快照差集 + 会话内容命中本次任务的输出文件名/汇总目录」，**不会误删你之前的会话**；
  命中不了的会话会打印 `[DSH] 保留会话 …` 供你核对。
- 若失败/被取消，同样会清理；原始输出会另存为 `artifacts\summary\<同名>.partial.md` 便于排查。

**任务失败会不会提示？** 会。以下情况都会在界面明确报错（红色提示 + 日志区留痕）：

| 情况 | 界面提示 |
|---|---|
| DSH 会话被中断（在 DSH 里停掉 / 超时） | `DSH 会话被中断…没有生成报告文件` |
| 你点了「停止该任务」 | `任务被取消，DSH 未生成报告文件（可重新运行）` |
| DSH 跑完但没写出报告文件 | `DSH 没有写出报告文件：artifacts/summary/…（请查看日志区输出）` |
| API 未配置 / Key 无效 / 余额不足 | `未配置 AI 服务：请到「设置」页添加…`、`返回 HTTP 401…` |

### ⑤ 文件汇总（PDF / Word / PPT / Excel 等）

用来把**不在群聊里的文档**也纳入总结（招聘公告、通知 PDF、培训材料、报名表等）。

1. **上传**：把文件拖进虚线框，或点「选择文件」。填一个批次名（例如 `2026-09-13-校招材料`），
   文件会存到 `artifacts\uploads\<批次>\`。
   - 单个文件上限 **40MB**；`.exe/.bat/.cmd/.ps1/.dll` 等危险后缀会被拒绝。
   - 同名文件会覆盖。
2. **解析**：点「开始解析」，调用本地 Python 抽文本（**不联网、不调用 AI**）。支持：

   | 类型 | 说明 |
   |---|---|
   | PDF | 抽文字层；**扫描版 PDF 会被识别并提示**（只出少量字符或提示无文字层），不会静默出空内容 |
   | Word `.docx` | 段落 + 表格 |
   | PPT `.pptx` | 每页标题与正文 |
   | Excel `.xlsx` | 各工作表转文本表格 |
   | 网页 `.html/.htm` | 去脚本样式后的正文 |
   | 文本 `.txt/.md/.csv/.json` | 直接读 |
   | 图片 | 可选 OCR（未装 OCR 引擎时会提示，不影响其他文件） |

3. **产物**（在 `artifacts\docs\<批次>\`）：`extracted\<文件名>.txt` 单文件文本、`files.json` 索引、`all-in-one.md` 合并全文。
4. **生成汇总**：勾选批次（或在下拉里选一个）→ 选「汇总引擎」→ 可选风格/关注点（或套用模板）→ 点「用 AI 汇总选中批次」。
   - **汇总引擎**：自动（默认，配了 AI 用 AI、没配用本地规则）/ 只用本地规则 / 只用 AI。页面下方会显示当前实际用哪条。
   - **提示词模板**：把常用的「风格要求 + 重点关注」存成模板，下次下拉一选即自动填充。
     「另存为模板」会让你给模板起名（同名覆盖），「删除模板」删除当前选中的模板。
     模板存在本机 `app\.local\config.json` 里，**不上传、不进 AI**。
   - 结果写入 `artifacts\docs\文件汇总-<批次>-<时间>.md`，在下方「文件汇总产物」里可**查看**或**打开目录**。
   - 每个批次还会另存一份 `artifacts\docs\<批次>\local-summary.md`（本地规则版的单批次汇总），它不会混进上面的产物列表。
5. **本地规则版汇总包含什么**（不联网、不调用 AI）：文件总览（类型/大小/字数/是否疑似扫描件）、
   每个文件的要点（开头标题行、章节结构、高频词、出现的日期、可能的要求与行动项）、
   **跨文件共性主题**、时间与截止/行动项汇总、关键数据（金额、百分比、电话、邮箱、链接）、待核实与缺口。
   > 它只做「归并 + 摘录 + 计数」，不做推理判断；要观点层面的结论，配好 AI 后重新生成即可升级为大模型版。
6. 解析结果也能被 ④ 总结页的「附加上传文件」选中，和群聊汇总合并总结。

> 想清掉测试文件：直接删 `artifacts\uploads\<批次>\` 与 `artifacts\docs\<批次>\` 即可，应用会自动忽略不存在的批次。

### ⑥ 设置

**聊天记录读取位置**（QCE 把记录导到哪，就在这里改）

| 控件 | 作用 |
|---|---|
| 当前状态 | 显示正在使用的两个目录、是否自定义、目录里有多少导出文件 |
| 手动导出目录 / 定时导出目录 | **留空 = 项目内默认**（`data/qq-chat-exporter/exports`、`…/scheduled-exports`）；也可填**绝对路径**（例如 `D:\QQChatExporter\exports`）或项目内相对路径 |
| 浏览… | 弹出目录选择器：可切盘符（C:/D:/E:）、逐级进入、用快捷入口（项目内默认目录、`我的文档\QQChatExporter`、`%LOCALAPPDATA%\QQChatExporter`），也能直接粘贴路径 |
| 校验 | 检查目录是否存在 / 能否读取 / 有几个导出文件 / 是否含 `resources` 媒体目录，并给出针对性提示 |
| 保存读取位置、保存并重新扫描 | 保存后立刻重新扫描导出列表，无需重启 |
| 恢复默认 | 两个都清空，回到项目内默认目录 |

要点：
- 支持**项目外目录**（导出在别的盘也能读）；跨盘归档会自动改为"复制后删除"。
- 校验提示会区分：目录不存在 / 无读取权限 / 目录里没有导出文件 / 缺少 `resources`（说明导出时没勾"下载图片/文件"）。
- 目录选择器遇到无效起点会自动回退到项目根，不会打不开。

- **AI 服务**：新增/编辑多个服务。预设涵盖 DeepSeek、阿里百炼、智谱、Moonshot、OpenAI、Anthropic、本地 Ollama，也可自定义任意 OpenAI 兼容端点（含中转站）。
- **API Key**：用 Windows 凭据保护（DPAPI，当前用户加密）保存在 `app\.local\secrets\`，界面只显示"已配置/未配置"。
- **按环节指定模型**：关键词推荐 / 分类复判 / 比对判定 / 总结，可分别指定 `服务id/模型名`；留空则用「当前使用」的服务。
- **单价表**：填各模型输入/输出单价（元/百万 token），用于费用估算；可建多套并切换。
- **运行环境**：端口、是否自动拉起 Edge/DSH、是否启动时打开浏览器。
- **分类与总结默认值**：分类模式、复判每批条数、默认采集条数、默认总结方式。

## 四、一键全流程

顶部「一键全流程」可以勾选本次要跑的步骤（群聊汇总 / AI 复判 / 推荐关键词 / 采集 / 交叉比对 / 生成总结），然后：

- **全自动**：按顺序跑完；
- **逐步可见**：日志区实时输出每一步的日志与进度条；
- **失败可续**：中途失败会停在该步并提示，修正后点「从断点继续」，已完成的步骤不会重跑；
- **可停止**：「停止」按钮终止流程；单个任务也可以在底部日志区选中后点「停止该任务」。

## 五、日志与排错

- 页面底部是**运行日志**：可以下拉切换任务、清空显示、终止任务。不同颜色：蓝色=系统提示，红色=错误，绿色=AI 输出。
- 常见情况对照：

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击后只有黑窗口，没看到界面 | 界面开在**调试 Edge 窗口**里（不是日常浏览器） | 去那个 Edge 窗口标签栏找；或手动访问黑窗口打印的地址 |
| 双击后窗口一闪而过 | 文件被编辑器改成了 UTF-8 带中文，cmd 解析失败 | 保证 `启动.cmd` 是**纯 ASCII**（中文提示只在 Node 输出里）；重新用仓库里的版本覆盖 |
| 提示 `Node.js not found` | 没装 Node 或不在 PATH | 装 Node 20+ 后重试 |
| 黑窗口报 `EADDRINUSE` | 端口全被占 | 到设置页改端口，或关掉占用程序 |
| 左侧「Edge 调试」红点 | Edge 调试实例没起 | 点左下「启动 Edge」；或看 `%LOCALAPPDATA%\dsh-edge-cdp` 是否被安全软件拦 |
| 左侧「DSH」红点 | DSH 没起 | 点左下「启动 DSH」，等十几秒 |
| 采集失败提示 `CDP port 9222 ...` | Edge 调试实例没起 | 同上；采集时也可自动拉起 |
| 采集 `exit_code` 非 0 | 未登录该平台 / 被风控 / 无结果 | 在 Edge 调试窗口里登录后重试，或换更具体的关键词 |
| 关键词验证刚开跑就失败，提示「…未登录或登录已过期」 | 采前登录判定没通过（**不是程序出错**） | 到 Edge 调试窗口重新登录对应平台再跑；已验证过：cookie 还在不代表登录有效 |
| 关键词验证日志里「xx 未登录或登录已过期，本次将跳过这些平台」 | 多平台里只有部分失效 | 属预期：其余平台继续采；想全采就去补登录 |
| 关键词验证「xx 采集未完成（超过 8 分钟…）」 | 平台风控/验证码/关键词过宽 | 降低条数、把关键词写具体、在 Edge 窗口里过掉验证码后重试 |
| 解析 PDF 后内容很少或提示无文字层 | 该 PDF 是**扫描件**（图片转的 PDF） | 属预期：需要 OCR；可先用其他工具转成有文字层的 PDF |
| 上传文件报「不支持的文件类型」 | 命中危险后缀黑名单 | 属预期：解压后单独上传里面的文档 |
| 上传报「文件过大」 | 超过 40MB | 拆分文件或压缩后上传 |
| 总结报「未配置 AI 服务」 | 走了 API 路径但没配服务 | 设置页新增服务并填 Key，或改用「本地 DSH」 |
| 汇总显示「媒体：未校验」 | 命令未带 `--media-check` | 界面默认已带；若手工跑脚本请补上 |
| 汇总里钟点与 QQ 差 8 小时 | QCE 导出自身的时间字段偏差 | 属预期（以时间戳为准），日期分组不受影响 |
| 总结报 `HTTP 401/403` | Key 无效或额度不足 | 检查 Key 与余额 |
| 一键流程停在某步 | 该步失败 | 看日志定位，修正后点「从断点继续」 |
| 点按钮"没反应" | 浏览器缓存了旧版 `app.js`；或本机同时跑着多个控制台进程 | 按 **Ctrl+F5** 强制刷新；启动器现在会检测已有实例并提示复用，不会再起第二个 |
| 启动时提示"读取汇总失败" | 旧版本汇总接口字段不全导致渲染报错 | 已修：接口改为返回完整结构（`mtime`/`files`/`building`），并对目录消失做容错 |
| 汇总完"已汇总"标签不刷新 | 旧版本只在结果里带 `outDir` 时才刷新 | 已修：任务完成/失败后按任务类型自动刷新（汇总→导出与汇总列表；采集→批次；比对→结果） |
| 「打开产物 / 打开 / 打开位置」没反应 | 旧版本把相对路径直接交给资源管理器；且失败被静默吞掉 | 已修：统一解析成绝对路径并用 ShellExecuteW 打开，**成功与失败都会弹提示** |
| 「停止」「停止该任务」点不动 | 没有流程/任务在跑时为置灰状态 | 属预期：有任务运行时才可点 |

- 所有产物都在 `artifacts\`（`qq\`、`social\`、`compare\`、`summary\`、`keywords\`、`uploads\`、`docs\`），随时可删、可重跑。
- 想彻底重置配置：删掉 `app\.local\` 目录（会同时清掉保存的 Key）。

## 六、界面上的"当前进程"与日志区

页面底部有两块：

**① 当前进程**（每 3 秒自动刷新）

| 列 | 含义 |
|---|---|
| 状态 | 运行中 |
| 任务 | 任务标题与类型（如「群聊汇总：xxx.json」） |
| PID | 该任务对应的系统进程号；旁边出现「已退出」说明进程已不在 |
| 已运行 | 从启动到现在的时间 |
| 启动的命令 | 实际执行的完整命令行（python/采集/DSH 等） |
| 终止 | 只终止这一个任务 |

最后一行还给出**控制台自身进程 PID** 与已运行时长，便于在任务管理器里对照。

**② 运行日志**

- 下拉框可选任意历史任务，选项里带 `[状态] 标题 PID 运行中时长`；实时日志通过 SSE 推送，逐行上屏。
- 颜色：蓝色=系统提示（含 `$ 命令`、`[进程] PID …`），红色=错误，绿色=AI 输出。
- 「停止该任务」终止下拉框里选中的任务；「清空显示」只清界面、不影响任务。
- 任何一步失败都会在日志区下方留下「最近一次失败：…」并在右下角弹红色提示（15 秒后可点击关闭），不会再出现"点了什么都没发生"的情况。

## 七、安全与边界

- **密钥**：DPAPI 加密落盘，只有当前 Windows 用户可解；不会上传到任何地方。
- **发给 AI 的内容**：走「我的 API」时，只发送**群聊汇总文本、社媒比对材料与上传文档抽出的文本**（不发送原始聊天记录文件、不发送图片二进制）；发送前有确认弹窗列出预估用量。
- **本地解析不上传**：文件解析（PDF/Word/Excel 抽文本）与关键词提取都在本机用 Python 完成，不联网、不经过任何 AI。
- **本地 DSH**：由你本机的 DSH 处理，数据不出本机（除 DSH 自身的模型请求）。
- **采集边界**：只读公开内容，不发布/不评论/不点赞，建议使用小号并控制频率；采集后端受上游许可限制（禁商用）。
- **登录态**：只读取你在 Edge 调试配置里已有的登录状态，不会读取或上传 cookie 值（登录检查脚本刻意只判断"存在与否"，并在需要时做一次真实登录判定）。
- **隐私**：`data\` 与 `artifacts\` 含真实群成员昵称与聊天内容，不要提交到公开仓库或上传网盘。
